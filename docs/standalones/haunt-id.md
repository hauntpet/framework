# haunt/id

## Installation

```shellscript
composer require haunt/id
```

### API Token

In order to connect to haunt you will need to register a new game: [https://haunt.pet/games/register](http://haunt.test/games/register). This will automatically generate an API Token for you to use which you will need to add to the `.env` file.

```dotenv
HAUNT_API_TOKEN="apitoken"
```
